# Home Connect

Node/Express + SQLite. Imeandaliwa kwa Render.

## Render
- Build Command: `npm install`
- Start Command: `npm start`
- Environment: ADMIN_PASSWORD, SESSION_SECRET, DATA_KEY (hex 64), NODE_ENV=production
- Hiari (WhatsApp): WA_TOKEN, WA_PHONE_ID, WA_ADMIN_TO, WA_TEMPLATE, WA_TEMPLATE_LANG

Tovuti (HTML/CSS/JS) iwe kwenye folda `public/`.
